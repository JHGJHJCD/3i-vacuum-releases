# הכלי לשליטה בשואב 3i: הורדה

כאן נמצא קובץ ההתקנה העדכני של הכלי לשליטה בשואב 3i S10 Ultra מהמחשב (Windows).

## הורדה

**[להורדת הגרסה העדכנית (3i-vacuum-portable.zip)](https://github.com/JHGJHJCD/3i-vacuum-releases/raw/main/3i-vacuum-portable.zip)**

גרסה נוכחית: 0.2.0, נבנתה ב-15.11.2026.

## התקנה ראשונה

1. מורידים את הקובץ ופותחים את ה-ZIP.
2. מעבירים את `3i-vacuum.exe` לתיקייה משלו (אפשר גם בדיסק-און-קי).
3. מפעילים בלחיצה כפולה. הממשק נפתח בדפדפן.
4. הוראות מלאות נמצאות בקובץ `instructions.html` שבתוך ה-ZIP.

## עדכון מגרסה קודמת

1. סוגרים את הכלי.
2. מחליפים את `3i-vacuum.exe` הישן בחדש.
3. מפעילים. ההגדרות, החדרים ומפת הכיסוי נשמרים בתיקייה `3i-vacuum-data` שליד הקובץ, ולא נמחקים.

## מה חדש בגרסה הזו

- ציור חדרים על המפה: מסמנים חדרים במלבנים, ולוחצים על חדר כדי לבחור אותו לניקוי.
- הכפתור "קרא חדרים מהשואב": ממלא לבד את המספר והשם של כל חדר, כדי שהשואב ייסע לחדר הנכון.
- תיקון: הקו של המסלול הנוכחי לא הצטייר בניקוי שני.

## בדיקת שלמות הקובץ

הקובץ `latest.json` מכיל את הגודל ואת ה-SHA-256 של הקובץ העדכני.

## הערות

- אין בקובץ סיסמאות או פרטים אישיים. פרטי החשבון נשמרים אצל כל משתמש בנפרד, במחשב שלו.
- הכלי אינו מוצר רשמי של היצרן.
